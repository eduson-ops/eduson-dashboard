# Run rate в рейтинге команды

## Цель

Показать прогноз выручки к концу текущего месяца для каждого менеджера и команды рядом с фактической выручкой и средним чеком.

## Интерфейс

- В таблице «Рейтинг команды» остаются колонки «Менеджер», «МК», «Оплат», «Конв.» и «Выручка».
- Колонка «₽/МК» заменяется на «Ср. чек».
- После неё добавляется колонка «Run rate» с подсказкой о формуле.
- Строка «Итого» показывает командный run rate и долю от плана выручки текущего месяца.
- Для режима «Весь месяц» показывается прогноз. Для недели и произвольного периода выводится `—`.
- На мобильном таблица сохраняет горизонтальную прокрутку.

## Расчёт

`runRate = revenue / elapsedCalendarDays * totalCalendarDays`

- Каждый календарный день считается рабочим днем отдела продаж.
- Текущий день входит в число прошедших календарных дней.
- Если прошедших календарных дней или выручки нет, результат равен нулю.
- Переключатель продлений влияет на выручку, средний чек и run rate одинаково.
- План загружается из листа «Таргеты» и не хардкодится.

## Границы изменений

- Меняется только `index.html` и тест расчёта.
- `loadAll()`, `fetchCSV()`, `SHEET_ID`, URL источников и автообновление не меняются.
- Новые внешние зависимости не добавляются.
- Сортировка рейтинга остаётся по фактической выручке.

## Проверка

- Формула проверяется для начала, середины и конца месяца, выходного дня и нулевой выручки.
- Проверяется таблица с включёнными и выключенными продлениями.
- Проверяются тёмная и светлая темы, основной и мобильный размеры.
- После push проверяется опубликованная страница GitHub Pages.
