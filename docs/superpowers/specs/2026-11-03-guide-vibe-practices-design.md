# Справка: вайбкодинг и практики

## Цель

Вернуть в раздел «Справка» описание практик из отдельного приложения `vibe-practice`.

## Решение

- добавить вкладку «Вайбкодинг»;
- показать три практики: 2D-платформер, 2D-игра-аркада и лендинг своего продукта;
- использовать названия и описания из исходного `PROJECTS` без добавления непроверенных ссылок;
- не менять букинг, аналитику и источники данных дашборда.

## Критерий проверки

Опубликованный `index.html` содержит вкладку `vibe`, три карточки практик и переключатель `showGuideTab`.
