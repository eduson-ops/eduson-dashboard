# Визуальный проход dashboard

Проход выполнен по принципам `unslop` для operational-интерфейса: спокойная рабочая поверхность, один основной акцент, явные статусы и меньше декоративного шума.

Изменения в `index.html`:

- отключён слой сезонных частиц;
- убраны фоновые радиальные градиенты для основных тем;
- уменьшены тени и радиусы панелей;
- заголовки переведены на основной sans-шрифт без display-эффекта;
- emoji-навигация заменена на компактные текстовые glyphs;
- сохранены цвета `.slot-0`, `.slot-red`, `.slot-amber`, `.slot-green`, Chart.js и существующие DOM-ID.

Источник направления: [heydamir/unslop](https://github.com/heydamir/unslop). В репозиторий не копировались файлы skill; применены только его визуальные принципы.
